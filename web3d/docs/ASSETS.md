Every asset in Second Ball 3D, where it comes from, and the licence that allows it here.

| Asset | Where it is | Source | Licence |
|---|---|---|---|
| Player character and animations (idle, walk, jog, sprint, dance, plus roll, sit and jump, which are kept but not yet used) | `public/models/mannequin.glb` | **Universal Animation Library (Standard)** by Quaternius: [quaternius.com](https://quaternius.com/packs/universalanimationlibrary.html), [OpenGameArt](https://opengameart.org/content/universal-animation-library). | Club colours and patterns | `src/three/kits.ts` | Invented for the 13 fictional clubs | Ours |
| Turf, pitch markings, LED boards, goal nets, ball, floodlight glow | `src/three/textures.ts` | Drawn on a canvas in code at start-up; no image files | Ours |
| Stadium, stands, roofs, tifo, big screen, sky | `src/three/stadium.ts`, `src/three/stands.ts` | Built from three.js primitives in code | Ours |

| Match data | `public/matches/*.jsonl` | Generated by the Second Ball engine: fictional clubs, invented players, synthetic data | Ours |

There are no sounds, music, photos, logos or third-party textures.

No real club, league, player or broadcaster is imitated. The clubs, names and kits are fictional.
