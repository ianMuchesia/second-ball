# Evaluation

Three questions, each measured by code, never by a model's opinion of itself:

1. **Moments: does the system notice the right things?** The moment detector
   against the demo's answer key (recall, precision), and on 50 free matches
   that nothing spams. Report: [Moment detector eval](#moment-detector-eval).
2. **Lines: is what airs true, and in time?** Real-model recordings of the
   demo: how many lines the model wrote (not templates), whether every agent
   answered, latency per line, cost. Repeat runs measure how often the first
   draft passes. Reports: [Foundry recordings](#foundry-recordings-of-the-demo),
   [Narration: repeat runs](#narration-repeat-runs),
   [Latency per stage](#latency-per-stage-live-demo).
3. **The Verifier: does the checker block false lines, and only those?** Every
   draft it blocked in a real run, labelled by Ian (real mistake, false alarm,
   style only, wrong reason), run through today's Verifier: no false alarms,
   every real error blocked for the right reason. Report:
   [Verifier accuracy](#verifier-accuracy-on-real-caught-drafts).

## Promotion gate

A recording becomes the demo bundle, and a change to a model, prompt or the
Verifier is kept, only if all of these hold. Applied by hand before a
promotion; the Verifier and test items are enforced by `make test`. Item 3's thresholds
were set by Ian on 2026-10-25; item 5 is the 8 s target each line already shows. **The gate is not passed
today: items 2 and 5 are not met.**

  its margin under the 5 s limit is thin on a slow machine.

  (Gemini and the fake model); they have not been re-run on Foundry.

## Known limits

- Red-card impact compares the 10 minutes before and after the card, so it is
  detected 10 minutes later; its clock is the red card's.
- Control shift compares consecutive 10-minute windows from 20' on, so a team
  taking control in the first minutes is not a "shift".
- Counters (for repeated_pattern) are read from events only: ball won in
  the team's own half, then within 10 s a 20 m+ forward pass into a wide
  channel beyond the defenders' back line. Full-back roles are not in the
  feed, so "behind the same full-back" = the same side of the same defence.
