# English words

`english.txt.gz`: the lowercase words of SCOWL's `american-english` list
(Debian `wamerican`), one per line. The Verifier uses it for one thing: a
capitalised word that starts a sentence ("Patient passing...", "Meanwhile...")
is an ordinary English word, not an unknown player's name ("Okafor ...").

SCOWL (Spell Checker Oriented Word Lists), http://wordlist.sourceforge.net/
